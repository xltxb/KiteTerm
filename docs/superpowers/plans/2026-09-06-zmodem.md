> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** SSH 会话中支持 lrzsz 的 `sz`/`rz`:自动探测握手、由 Rust 状态机收发文件、进度显示在终端浮条与传输页,完成后回到终端模式。

**Architecture:** 新增 `src-tauri/src/zmodem/` 模块。`frame.rs` 是纯函数(CRC、ZDLE 转义、帧编解码、增量解析器),不依赖 Tauri。`receive.rs`/`send.rs` 是泛型于 `ZChannel` trait 的异步状态机,进度经 `ProgressSink` trait 上报,故可用内存管道做回环测试而不碰 Tauri。`mod.rs` 提供 `Detector`、`ZChannel`/`ProgressSink` trait 与 `run(ctx)` 入口。`ssh.rs` 的 `run_session` 在收到通道数据时经探测器识别握手头,命中即把通道交给 `run`,期间不进终端与录制。

**Tech Stack:** Rust(edition 2021, rustc 1.98,trait 原生 async fn)/ russh / tokio / Tauri 2 / React + Zustand。

**Spec:** `docs/superpowers/specs/2026-09-06-zmodem-design.md`

//! ZMODEM 帧的纯函数编解码:CRC、ZDLE 转义、帧头与数据子包、增量解析器。不依赖 Tauri。

pub const ZPAD: u8 = b'*';
pub const ZDLE: u8 = 0x18;
pub const ZBIN32: u8 = b'C';
pub const ZHEX: u8 = b'B';

pub const ZRQINIT: u8 = 0;
pub const ZRINIT: u8 = 1;
pub const ZSINIT: u8 = 2;
pub const ZACK: u8 = 3;
pub const ZFILE: u8 = 4;
pub const ZSKIP: u8 = 5;
pub const ZNAK: u8 = 6;
pub const ZFIN: u8 = 8;
pub const ZRPOS: u8 = 9;
pub const ZDATA: u8 = 10;
pub const ZEOF: u8 = 11;
pub const ZFERR: u8 = 12;
pub const ZCAN: u8 = 16;

pub const ZCRCE: u8 = 0x68;
pub const ZCRCG: u8 = 0x69;
pub const ZCRCQ: u8 = 0x6a;
pub const ZCRCW: u8 = 0x6b;

pub fn crc16(data: &[u8]) -> u16 {
    let mut crc: u16 = 0;
    for &b in data {
        crc ^= (b as u16) << 8;
        for _ in 0..8 {
            crc = if crc & 0x8000 != 0 { (crc << 1) ^ 0x1021 } else { crc << 1 };
        }
    }
    crc
}

pub fn crc32(data: &[u8]) -> u32 {
    let mut crc: u32 = 0xFFFF_FFFF;
    for &b in data {
        crc ^= b as u32;
        for _ in 0..8 {
            crc = if crc & 1 != 0 { (crc >> 1) ^ 0xEDB8_8320 } else { crc >> 1 };
        }
    }
    crc ^ 0xFFFF_FFFF
}

/// 需要转义的字节:ZDLE 本身与常见流控/telnet 敏感字节
fn needs_escape(b: u8) -> bool {
    matches!(b, 0x18 | 0x10 | 0x11 | 0x13 | 0x90 | 0x91 | 0x93)
}

pub fn zdle_escape(out: &mut Vec<u8>, data: &[u8]) {
    for &b in data {
        if needs_escape(b) {
            out.push(ZDLE);
            out.push(b ^ 0x40);
        } else {
            out.push(b);
        }
    }
}

pub fn pos_to_arg(pos: u32) -> [u8; 4] {
    pos.to_le_bytes()
}
pub fn arg_to_pos(arg: [u8; 4]) -> u32 {
    u32::from_le_bytes(arg)
}
```

/// 十六进制帧头:`**` ZDLE 'B' + 7 字节(kind+arg4+crc16)转小写 hex + CR LF(0x8a)
pub fn encode_hex_header(kind: u8, arg: [u8; 4]) -> Vec<u8> {
    let body = [kind, arg[0], arg[1], arg[2], arg[3]];
    let crc = crc16(&body);
    let mut raw = body.to_vec();
    raw.push((crc >> 8) as u8);
    raw.push((crc & 0xff) as u8);
    let mut out = vec![ZPAD, ZPAD, ZDLE, ZHEX];
    for b in raw {
        out.push(hex_nibble(b >> 4));
        out.push(hex_nibble(b & 0xf));
    }
    out.push(0x0d);
    out.push(0x8a); // LF|0x80,lrzsz 惯例
    out
}

fn hex_nibble(n: u8) -> u8 {
    if n < 10 { b'0' + n } else { b'a' + (n - 10) }
}

/// 二进制 CRC32 帧头:`*` ZDLE 'C' + [kind+arg4] + crc32(LE),body 与 crc 经 ZDLE 转义
pub fn encode_bin32_header(kind: u8, arg: [u8; 4]) -> Vec<u8> {
    let body = [kind, arg[0], arg[1], arg[2], arg[3]];
    let crc = crc32(&body);
    let mut payload = body.to_vec();
    payload.extend_from_slice(&crc.to_le_bytes());
    let mut out = vec![ZPAD, ZDLE, ZBIN32];
    zdle_escape(&mut out, &payload);
    out
}

/// 数据子包:data 转义 + ZDLE + end,再 crc(覆盖 data 原始字节与 end)转义
pub fn encode_data_subpacket(data: &[u8], end: u8, use_crc32: bool) -> Vec<u8> {
    let mut out = Vec::new();
    zdle_escape(&mut out, data);
    out.push(ZDLE);
    out.push(end);
    if use_crc32 {
        let mut crc_input = data.to_vec();
        crc_input.push(end);
        let crc = crc32(&crc_input);
        zdle_escape(&mut out, &crc.to_le_bytes());
    } else {
        let mut crc_input = data.to_vec();
        crc_input.push(end);
        let crc = crc16(&crc_input);
        zdle_escape(&mut out, &[(crc >> 8) as u8, (crc & 0xff) as u8]);
    }
    out
}
```

`Parser` 实现要点(写在同文件):内部持 `buf: Vec<u8>`。`feed` 追加。`next` 从 `buf` 找 `ZDLE`(0x18)后跟 `B`(hex)、`A`(bin16)、`C`(bin32)或直接的数据子包上下文。为控制复杂度,`Parser` 维护一个 `expect_data: Option<bool>`(下一段是否为数据子包及是否 crc32,由收到 ZDATA/ZFILE 头后置上),据此在数据模式解析子包、在帧模式解析帧头。解析成功消费对应字节;不足一帧返回 `None`;CRC 不符返回 `Event::GarbledCrc` 并跳过该帧首字节以便重同步。解析时先做 ZDLE 反转义再校验 CRC。

```rust
#[derive(Debug)]
pub enum Event {
    Header { kind: u8, arg: [u8; 4] },
    Data { bytes: Vec<u8>, end: u8 },
    GarbledCrc,
}

pub struct Parser {
    buf: Vec<u8>,
    /// 收到 ZFILE/ZDATA 头后置为 Some(use_crc32),表示随后是数据子包流
    expect_data: Option<bool>,
}

impl Parser {
    pub fn new() -> Self {
        Self { buf: Vec::new(), expect_data: None }
    }
    pub fn feed(&mut self, bytes: &[u8]) {
        self.buf.extend_from_slice(bytes);
    }
    /// 收方在收到数据帧头后调用,切换到数据子包解析
    pub fn set_data_mode(&mut self, use_crc32: bool) {
        self.expect_data = Some(use_crc32);
    }
    pub fn set_header_mode(&mut self) {
        self.expect_data = None;
    }
    pub fn next(&mut self) -> Option<Event> {
        // 实现:数据模式下调用 parse_subpacket,帧模式下 parse_header;
        // 见下方私有方法。返回 None 表示需要更多字节。
        if self.expect_data.is_some() {
            self.parse_subpacket()
        } else {
            self.parse_header()
        }
    }
    // parse_header / parse_subpacket:按上文规则实现,含 ZDLE 反转义与 CRC 校验。
    // 反转义:遇 ZDLE 取下一字节 ^0x40。CRC 覆盖反转义后的原始字节。
}
```

实现者需补全 `parse_header`(识别 hex `B` 与 bin32 `C` 两种头,hex 头以 CR/LF 收尾)与 `parse_subpacket`(读到 `ZDLE end` 后跟 crc,end∈{ZCRCE,ZCRCG,ZCRCQ,ZCRCW};校验通过返回 `Data`,失败返回 `GarbledCrc`)。bin16(`A`)可只识别不测试。以测试驱动补全,直到 Step 5 的 5 个测试全过。

```rust

use std::io;

/// 抽象一条可读可写的字节通道:russh 通道、内存管道或本机 lrzsz 子进程 stdio
pub trait ZChannel {
    async fn read(&mut self, buf: &mut [u8]) -> io::Result<usize>;
    async fn write_all(&mut self, data: &[u8]) -> io::Result<()>;
}

/// 状态机向外报告进度,由 Tauri 侧实现为 TransferJob 事件,测试侧实现为记录器
pub trait ProgressSink {
    fn start(&self, direction: &str, name: &str, total: u64, index: usize, count: usize);
    fn advance(&self, transferred: u64);
    fn finish(&self, ok: bool, error: Option<String>);
}

#[derive(Debug, Clone, Copy, PartialEq)]
pub enum Detected {
    Receive, // 远端 sz,本机收
    Send,    // 远端 rz,本机发
}

/// 在终端输出流里滑窗匹配 zmodem 握手头
pub struct Detector {
    win: Vec<u8>,
}

impl Detector {
    pub fn new() -> Self {
        Self { win: Vec::new() }
    }
    pub fn push(&mut self, data: &[u8]) -> Option<(Detected, usize)> {
        // 维护不超过 8 字节的窗口 + 本次 data 拼接后查找 **\x18B00 / **\x18B01
        let base = self.win.len();
        self.win.extend_from_slice(data);
        let hay = &self.win;
        let find = |needle: &[u8]| hay.windows(needle.len()).position(|w| w == needle);
        let rq = find(b"\x2a\x2a\x18B00");
        let ri = find(b"\x2a\x2a\x18B01");
        let hit = match (rq, ri) {
            (Some(a), Some(b)) if a <= b => Some((Detected::Receive, a)),
            (Some(_), Some(b)) => Some((Detected::Send, b)),
            (Some(a), None) => Some((Detected::Receive, a)),
            (None, Some(b)) => Some((Detected::Send, b)),
            (None, None) => None,
        };
        if let Some((kind, at)) = hit {
            let in_data = at.saturating_sub(base); // 命中点在本次 data 中的下标
            self.win.clear();
            return Some((kind, in_data));
        }
        // 只保留尾部 7 字节以便跨 push 匹配
        if self.win.len() > 7 {
            let cut = self.win.len() - 7;
            self.win.drain(0..cut);
        }
        None
    }
}
```

pub async fn run<C: ZChannel, P: ProgressSink>(
    mode: Detected,
    ctx: RunCtx<'_, C, P>,
